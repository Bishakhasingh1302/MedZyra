MedZyra Health Website
=========================
Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it in Chrome/Safari.
3. Create an account. The demo asks for a password after the second registration step.
4. Data is stored in your browser's localStorage, so this is a front-end functional demo.
5. Login, health profile, appointments, documents, medicine tracker, settings and logout are functional.

Important:
This is a prototype only. Do not use real patient/medical data. A production healthcare system needs a secure backend, encrypted storage, authentication, authorization, audit logs, consent management and appropriate regulatory/privacy controls.
